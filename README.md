# Анализатор студенческих оценок

Командный проект по Java (Проект №4). 
Цель: статистика успеваемости, рейтинги и выявление студентов в зоне риска.

## Команда и роли:
* **Максим**: Данные (парсер CSV, валидация, генератор синтетики)
* **Дима**: Статистика (математические метрики, матрицы корреляции)
* **Глеб**: Модель риска (правила, оценка Precision/Recall)
* **Никита**: Интерфейс и отчеты (текстовые гистограммы, экспорт, Main)

## Как запустить (инструкция):
1. Убедитесь, что у вас установлена Java 11 или выше.
2. Скомпилируйте проект: `javac -d out $(find src -name "*.java")`
   *(для Windows: `javac -d out src/main/java/gradeanalyzer/*.java src/main/java/gradeanalyzer/*/*.java`)*
3. Запустите главный класс: `java -cp out gradeanalyzer.Main`
